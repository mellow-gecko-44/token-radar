Token launch radar: ranks pre-token DeFi protocols by implied token value from a sealed DefiLlama snapshot — 203 rows (40 watchlist + 163 early finds), a 7-step farm plan per protocol, and a sortable dark dashboard with a detail view per protocol. The model is category-median multiples from the snapshot's own live-token protocols, shrunk toward the overall median, times growth and maturity factors; no protocol name is ever special-cased.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
